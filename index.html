Why I built it this way

I treated forecasting like a deployment problem: chronological validation, strong naive baselines, a separate final holdout, modular production code, and explicit limits around what surveillance predictions can and cannot claim.

Behavioral + Audio ML

Predicting Spotify Skips from Song Intros

A multimodal ML study using 92,445 personal streaming events and 10-second audio previews to compare handcrafted features, CNNs, Audio Spectrogram Transformers, listening context, and fusion models.

The result that surprised me

Listening context explained substantially more of my skip behavior than the audio itself. I kept the context-only control in the project because it made the conclusion more honest, even though it weakened the original audio-first hypothesis.

Simulation · Monte Carlo

Wildfire Spread on a Real Deforestation Frontier

Used a cellular-automata model and Amazon deforestation data to test how targeted interventions change wildfire spread across high-risk landscapes.

Result: targeted intervention reduced simulated burned area by up to 83.8% across 500 Monte Carlo runs.
Report ↗ Code ↗
Bayesian Modeling · PyMC

Sports Attendance in Argentina

Modeled football attendance with a hierarchical Negative Binomial model, team and day effects, posterior predictive checks, and PSIS-LOO model comparison.

Result: the hierarchical model produced better predictive performance and more realistic uncertainty than simpler pooled alternatives.
Report ↗ Code ↗
Algorithms · Dynamic Programming

Decoding Relationships Between Genes

Reconstructed genealogical relationships from DNA strings using Longest Common Subsequence, a pairwise similarity matrix, and greedy versus global tree construction.

Tradeoff: global DP improved the objective from 1336 → 1442, but runtime grows exponentially—making the quality/complexity tradeoff explicit.
